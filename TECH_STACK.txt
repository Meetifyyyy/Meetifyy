-------------------------------------------------------------------------------
1. TECH STACK (SHORT)
-------------------------------------------------------------------------------

FRONTEND (frontend/)
  React 18 + Vite 6 (JavaScript, not TS)
  Routing ......... React Router 7
  State ........... Zustand + Immer, TanStack Query (server state)
  Forms ........... React Hook Form + Zod
  UI .............. Plain CSS (144 files, no Tailwind), Framer Motion
  Icons ........... HugeIcons, Heroicons
  Realtime ........ socket.io-client
  Extras .......... emoji-mart, Fuse.js (search), react-easy-crop,
                    browser-image-compression, Sonner (toasts)
  PWA ............. vite-plugin-pwa (injectManifest, custom sw.js)
  Tests ........... Vitest

ADMIN PANEL (admin-frontend/)
  React 19 + Vite + TypeScript
  TanStack Query + TanStack Table, Recharts, Lucide, Framer Motion
  Lint: oxlint

BACKEND (backend/)
  NestJS 11 on Node 22 (TypeScript)
  API ............. Express platform, class-validator / class-transformer
  ORM ............. Prisma 6 + @prisma/adapter-pg (node-postgres driver)
  Realtime ........ socket.io (@nestjs/websockets)
  Queues .......... BullMQ + Redis
  Auth ............ Supabase Auth, JWT, bcryptjs, otplib (2FA)
  Email ........... Resend + React Email, Nodemailer (Mailpit in dev)
  Storage ......... Cloudflare R2 via AWS S3 SDK (presigned URLs)
  Security ........ Helmet, rate-limiter-flexible, sanitize-html
  Logging ......... Pino (nestjs-pino), Sentry (errors + profiling)
  Tests ........... Jest (39 suites / 542 tests)

DATA
  PostgreSQL on Supabase (transaction pooler, port 6543)
  Prisma migrations; DIRECT_URL used for migrations only
  Redis — queues, cache, presence

INFRASTRUCTURE
  Backend ......... Docker -> Azure Container Registry -> Azure Container Apps
                    (region: uaenorth; internal Redis container)
  Frontend/Admin .. Vercel
  DNS/CDN ......... Cloudflare
  CI/CD ........... GitHub Actions (ci.yml, deploy-dev.yml, deploy-prod.yml)
                    OIDC federated auth to Azure (no stored passwords)

ENVIRONMENTS
  dev.meetifyy.app ....... frontend (Vercel)
  dev-api.meetifyy.app ... backend  (Azure Container Apps)
  production ............. not provisioned yet
